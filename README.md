# CS50's Introduction to Artificial Intelligence with Python (HarvardX)

This repository contains my solutions and projects for Harvard University's CS50AI course. As an **Aerospace Engineer**, my goal is to bridge the gap between aerospace systems and advanced AI techniques, focusing on optimization, autonomous decision-making, and intelligent control systems.

## 🛠️ Tech Stack & Tools
* **Language:** Python 3
* **IDE:** Visual Studio Code (VS Code)
* **Key Concepts:** Search Algorithms, Knowledge Representation, Probability, Optimization, Machine Learning, Neural Networks.
